# MAX Chat · GREEN-API

Минималистичный веб-чат на **React + TypeScript** для отправки и получения текстовых сообщений в мессенджере **MAX** через сервис [GREEN-API](https://green-api.com/max). Внешний вид вдохновлён [web.max.ru](https://web.max.ru/).

Тестовое задание на позицию «Фронтенд разработчик React».

## Возможности

- Вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`) с проверкой через `getStateInstance`
- Создание нового чата по номеру телефона получателя (`CheckAccount` → `chatId`)
- Отправка текстовых сообщений — метод [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)
- Получение ответов — [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/): `ReceiveNotification` + `DeleteNotification` (long-polling)
- Список чатов, счётчик непрочитанных, статусы сообщений (отправляется / отправлено / ошибка с повтором)
- История сохраняется в `localStorage` отдельно для каждого инстанса
- Адаптивная вёрстка (на телефоне — список чатов и окно чата как отдельные экраны)

## Требования

- [Node.js](https://nodejs.org/) **18.18+** (проверено на 22) и npm
- Аккаунт в [личном кабинете GREEN-API](https://console.green-api.com) с созданным и **авторизованным** инстансом MAX

## Инструкция для локального запуска

### 1. Подготовьте инстанс GREEN-API

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com) и создайте инстанс (подойдёт бесплатный тариф).
2. Авторизуйте инстанс: в приложении MAX на телефоне откройте `Профиль → Устройства → Войти по QR-коду` и отсканируйте QR-код из личного кабинета.
3. Скопируйте со страницы инстанса **`idInstance`** и **`apiTokenInstance`**.
4. Включите получение уведомлений через HTTP API: в настройках инстанса поле `webhookUrl` должно быть **пустым**, а уведомления о входящих сообщениях (`incomingWebhook`) — включены. Либо выполните метод [`SetSettings`](https://green-api.com/v3/docs/api/account/SetSettings/):

   ```json
   {
     "webhookUrl": "",
     "incomingWebhook": "yes"
   }
   ```

   После изменения настроек подождите около минуты.

### 2. Запустите приложение

```bash
git clone https://github.com/Vovanisimous/max-chat-green-api.git
cd max-chat-green-api
npm install
npm run dev
```

Откройте в браузере адрес из консоли (по умолчанию <http://localhost:5173>).

### 3. Проверьте сценарий

1. На экране входа введите `idInstance` и `apiTokenInstance`.
2. Нажмите на значок карандаша в шапке списка чатов и введите номер получателя, например `+7 999 123-45-67`.
3. Напишите сообщение и отправьте его (`Enter` — отправить, `Shift+Enter` — новая строка).
4. Попросите получателя ответить в MAX — ответ появится в чате в течение нескольких секунд.

> Номер получателя должен быть зарегистрирован в MAX (поддерживаются номера РФ и РБ — это ограничение метода `CheckAccount`).

## Конфигурация

По умолчанию запросы идут на `https://api.green-api.com`. Если для вашего инстанса указан другой `apiUrl`, его можно:

- ввести на экране входа в разделе «Дополнительно», или
- задать переменной окружения `VITE_GREEN_API_URL` (см. `.env.example`).

## Как это устроено

```
src/
├── api/
│   ├── greenApi.ts        # клиент GREEN-API: sendMessage, checkAccount, receive/deleteNotification
│   └── notifications.ts   # разбор входящих уведомлений
├── hooks/
│   ├── useNotifications.ts  # цикл long-polling с повторами и backoff
│   └── useChats.ts          # состояние чатов + сохранение в localStorage
├── state/
│   ├── chatReducer.ts     # чистый reducer (дедупликация, непрочитанные, сортировка)
│   └── storage.ts         # localStorage
├── components/            # LoginScreen, Messenger, Sidebar, ChatWindow, NewChatDialog …
└── utils/                 # форматирование времени и номеров телефона
```

Как работает получение сообщений: после входа запускается цикл `ReceiveNotification` (ожидание до 5 секунд) → обработка уведомления → `DeleteNotification`. Входящие текстовые сообщения (`incomingMessageReceived`) попадают в соответствующий чат, остальные уведомления подтверждаются и пропускаются. При ошибках сети цикл повторяет запрос с нарастающей паузой, при ответе 401/403 — разлогинивает пользователя.

## Замечания

- `idInstance` и `apiTokenInstance` хранятся в `localStorage` браузера, чтобы не вводить их при каждом открытии. Кнопка «Выйти» удаляет их; для публичного развёртывания учитывайте, что токен доступен коду страницы.
- GREEN-API хранит очередь уведомлений 24 часа. Если опрос выполняет другой клиент или включён `webhookUrl`, `ReceiveNotification` вернёт ошибку или пропустит сообщения.
- Реализованы только текстовые сообщения; файлы и другие типы вложений игнорируются.
